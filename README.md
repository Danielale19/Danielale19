#### 🏥 MediConnect — architecture réseau sécurisée

<div align="center">

[![MediConnect](https://github-readme-stats.vercel.app/api/pin/?username=Danielale19&repo=mediconnect-secure-network&bg_color=0d1117&title_color=00ff9c&text_color=c9d1d9&icon_color=00ff9c&border_color=30363d)](https://github.com/Danielale19/mediconnect-secure-network)

</div>

```bash
mediconnect/
├── segmentation    → 6 zones pfSense : DMZ isolée, bastion d'admin, refus par défaut
├── accès distant   → VPN IPsec IKEv2 + OpenVPN par profil
├── identité        → OpenLDAP (LDAPS), PKI interne, accès médecins en mTLS
├── filtrage        → règles par groupe LDAP : support, admins, commerciaux
├── détection       → Suricata, pfBlockerNG, Wazuh (décodeurs & règles custom)
└── validation      → 9 scénarios de test depuis Kali, rapport complet + vidéo
```

`pfSense` `Wazuh` `Suricata` `OpenVPN` `IPsec` `OpenLDAP` `nginx` `VirtualBox`
